# Photo Gallery

A responsive photo gallery that loads 30 photos from Picsum Photos. Search by author name and save favourite photos in the browser.

## Features

- Responsive photo grid
- Search photos by author
- Favourites saved between page visits
- Loading and error messages

## Tech stack

- React with JavaScript and Vite
- Tailwind CSS
- Picsum Photos API
- Browser localStorage

## Run locally

```bash
npm install
npm run dev
```

Open the local address printed in the terminal.
